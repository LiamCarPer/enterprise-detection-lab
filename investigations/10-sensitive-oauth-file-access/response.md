# Response — INV-010

1. Revoke the user's consent and refresh tokens.
2. Disable or remove the application service principal after preserving evidence.
3. Revoke application credentials and review granted permissions.
4. Review SharePoint and OneDrive access for the application and other consenting users.
5. Remove external sharing or permission changes created by the application.
6. Reset the user's credentials if the originating session is suspicious.
7. Add the application to a tenant deny or approval workflow.
8. Review other file, mail, and Teams activity by the application.
