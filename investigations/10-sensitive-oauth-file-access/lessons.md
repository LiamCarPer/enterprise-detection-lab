# Lessons — INV-010

- User consent with offline access can create durable application access to files without another password prompt.
- The consent record identifies the application and scopes, but not the application publisher's intent.
- File access and download by the application are observed; token exchange and actor attribution remain inferred.
- The application is absent from the approved inventory and has failed publisher and redirect trust; the inventory and reputation feed must be maintained.
- Admin consent and tenant-wide grants are separate paths with different approval expectations.
- A single file operation is weak evidence; volume, site sensitivity, and external sharing should drive escalation.
