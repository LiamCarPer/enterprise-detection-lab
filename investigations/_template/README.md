# Reference Investigation — Synthetic Identity to Cloud

This is a reference artifact used by `edl new investigation`. It is synthetic and not a production incident.

## Scenario

A synthetic OAuth consent event is observed, followed by a cloud role assumption.

## Scope

- Identity: Entra ID audit event
- Cloud: assumed role and data access

## Hypothesis

A consent grant can precede cloud role assumption and data access.
