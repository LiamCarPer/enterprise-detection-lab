# Reports

`detection-metrics.md` is generated by `edl detection report`. Do not edit it by hand. The report aggregates the committed `metrics.json` files for every detection and states the synthetic-fixture limitations explicitly.

`false-positive-tuning.md` documents the baseline measurement and tuning change for `DET-END-001`.

`benign-baseline-results.md` summarizes the identity, endpoint, cloud, SaaS, network, and scenario baseline results and their limitations.

Regenerate it after changing detection metrics:

```bash
make metrics-report
```

Verify that it is current:

```bash
make metrics-check
```
